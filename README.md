# Intrusion-Detection-using-Machine-Learning
This project implements an Intrusion Detection System (IDS) using the CICIDS2017 dataset, focusing on detecting various network attacks such as DoS, DDoS, PortScan, and Brute Force. It leverages a combination of machine learning and deep learning models, including Gradient Boosting, a Voting Ensemble of SVM, KNN, and Naïve Bayes, and a Multilayer Perceptron (MLP). The dataset is preprocessed with feature selection techniques to improve model performance, and the models are evaluated using metrics like accuracy, precision, recall, and F1-score. The goal is to compare the effectiveness of ensemble learning and deep learning in intrusion detection, providing insights into their strengths in identifying malicious traffic.
